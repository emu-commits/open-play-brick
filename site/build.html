Install the firmware

Plug the Feather into this computer with a USB-C data cable, then click the button. Works in Chrome and Edge on a desktop or laptop. It installs firmware … and the tag catalogue, and afterwards shows the brick's console.

This browser cannot talk to USB serial devices. Use Chrome or Edge on a computer. The installer needs a secure (https) page.

This firmware compiles and passes its tests in the emulator. It has not yet been run on a real board.
